发一篇文章只需要两步：建文件、写内容。

<!-- more -->

## 用命令创建

```bash
npx hexo new "文章标题"
```

会在 `source/_posts/` 下生成 `文章标题.md`。也可以不敲命令，直接在那个目录里手动新建 `.md` 文件，效果一样。

## Frontmatter

文件最上面用 `---` 包起来的这段叫 frontmatter，决定文章的标题、时间和归类：

```yaml
---
title: 文章标题
date: 2026-11-11 20:00:00
categories:
  - 笔记
tags:
  - Hexo
  - Markdown
---
```

`categories` 是有层级的，写两个会变成「父分类 / 子分类」；`tags` 是平级的标签。两者都可以省略。

> 本站的永久链接配置是 `permalink: :title/`，所以文件名就是 URL。想用英文路径，把文件名写成英文即可，标题仍可保持中文。

## 摘要与正文分隔

在想要截断的位置插入一行：

```markdown
<!-- more -->
```

首页列表只显示这行之前的内容，点进文章才看全文。不写也没关系，Fluid 会自动截取开头一段。

## 本地预览

```bash
npm run dev
```

浏览器打开 `http://localhost:4000`。`hexo server` 会监听文件变化，边写边看。

## 草稿

还不想发布的内容放到 `source/_drafts/`，或者用 `npx hexo new draft "标题"` 创建。默认不会生成到站点；想预览时加 `--draft` 参数。

## 发布

确认没问题后：

```bash
npm run build
git add .
git commit -m "post: 新文章"
git push
```

推送之后，Netlify 或 GitHub Pages 的构建流程会自动生成并上线，不需要手动上传 `public/`。
