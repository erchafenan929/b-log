博客搭好了。

这套东西是 **Hexo 8 + Fluid 主题**：纯静态、没有数据库、没有后台，文章就是一个个 Markdown 文件躺在 `source/_posts/` 里。写完执行 `npm run build`，生成 `public/`，把它丢到 Netlify 或 GitHub Pages 就能访问。

<!-- more -->

## 为什么要自己搭一个

用现成的平台当然省事，但文章寄存在别人那里，格式、导出、域名都由不得自己。静态博客把内容还原成最朴素的形式——一个文本文件，放到任何地方都能读，十年后也还在。

顺带的好处是：写作用 Markdown，版本历史用 Git，想改样式就直接改主题配置，没有黑盒。

## 现在能做什么

- 在 `source/_posts/` 下新建一个 `.md` 文件，就是发了一篇文章
- 用 frontmatter 里的 `categories` 和 `tags` 归类，站点会自动生成分类页与标签页
- 本地执行 `npm run dev` 可以边写边预览，保存即刷新
- 导航栏的搜索、归档、关于页都已经配好

## 接下来

先去 `README.md` 把标题、作者、域名换成自己的，再删掉这几篇示例文章，就可以正式开写了。

> 博客最难的不是搭起来，是持续往里面放东西。慢慢来。
